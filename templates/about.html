AI-Powered Music Recommendations

This project presents a song recommendation system using a chatbot, integrating AI-based sentiment analysis and song suggestions. The system utilizes an AI API key for natural language processing to enable real-time interactions with users. Through conversational exchange, the chatbot assesses the user's emotional state—categorizing it as happy, sad, or neutral—using sentiment analysis techniques.

Key Features

  • 🤖 AI-Powered Chatbot
  • 💭 Sentiment Analysis
  • 🎵 Letest Bollywood Songs
  • 🎯 Personalized Recommendations
